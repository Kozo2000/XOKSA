News & Fundamentals

News (one of XOKSA's three views). Shows a stock's recent headlines — a clue to why it moved. Titles and links only; article bodies are not fetched. Showing news requires a Brave Search API key.

Fundamentals (one of XOKSA's three views). Shows a company's financials (PER/PBR/ROE, earnings). US stocks use SEC EDGAR public data — the SEC asks you to identify the caller with a User-Agent (your name + email); no key or charge. Japanese stocks need a J-Quants API key.

Point at the JPX "Listed Securities List" (data_j.xls) directly — no Excel conversion needed. A CSV works too (UTF-8). Column 2 = code, column 3 = name.

Connection

Off by default (loopback only). When on, other devices on your network can open the dashboard — sign-in with the access token is always required (the engine generates one automatically and refuses unauthenticated access), and only private-network addresses are accepted. Share the token only with devices you trust, and keep this on trusted networks (LAN/VPN) — never the open internet.

The port the dashboard listens on (default 8787). Change it if another program already uses that port; remote devices must use the same number.

Save first, then restart: a new port or access token only takes effect on an engine that started after the change.

Chat notifications

Optional. While the app is running, alerts push a one-line message to your chat (Slack / Discord / Google Chat / LINE). The secret (webhook URL, or LINE bot token) is stored in your OS keychain — leave it blank to keep the one already saved. Define watch rules in xoksa.env or with /alert in the dashboard chat.
